# Designs Tokens With Style Dictionary

This is a design tokens file that can be used to generate design tokens using Style Dictionary.

## Diagram

![Design Tokens transformation using Style Dictionary](https://raw.githubusercontent.com/navdeepsingh/navsara-design-system-1.0/refs/heads/develop/public/Design-Tokens-Style-Dictionary.png)

## Installation

```bash
npm install
```

## Build

```bash
npm run build
```
